# TOPページ第2フェーズ 情報設計・SEO計画 2026-08-07

## 結論

今回の改修では、公開済みの記事・事例・サービスのURLを `/ai/` 配下へ移動しない。

- `/`: 株式会社コールテン全体のホームページ
- `/ai/`: AI事業の入口
- `/blog/<slug>/`: AI記事と会社記事の両方を置く既存メディア。公開済みURLを維持する
- `/services/<slug>/`: 既存のAIサービス詳細。公開済みURLを維持する
- `/voices/<slug>/`: 既存の事例。公開済みURLを維持する
- `/dream/boardgame-cafe/`: 将来の場づくり構想

URLを変えず、ナビゲーション、記事分類、内部リンク、見出しで所属を明確にする。これにより既存の被リンク、検索評価、SNS共有URL、構造化データを維持する。

## 現状認識

旧トップを `/ai/` に保全したことによって変わったのは「AI事業トップの入口」であり、既存のブログ記事やサービスページのスラッグではない。現在の各記事は以前から `/blog/.../`、サービスは `/services/.../` に存在する。

したがって、次の移動は行わない。

- `/blog/example/` から `/ai/blog/example/` への移動
- `/services/advisory/` から `/ai/services/advisory/` への移動
- `/voices/sano/` から `/ai/voices/sano/` への移動

この移動はSEO上の利益が小さい一方、301、canonical、内部リンク、外部リンク、Search Consoleの再評価が必要になり、順位変動リスクが大きい。

## デザイン改善

### Hero

- 背景を左右端まで確実に広げる。
- 右側の布テクスチャを「余白のように見える帯」ではなく、画面端まで届く明確な構成要素にする。
- 文字面と布面の境界に細い赤線と事業姿勢の縦ラベルを置き、編集的な強さを出す。
- 黄色・生成りのHeroからTiki / Tetoを外す。キャラクターはイントロ、社名の由来、相談セクションなど、意味のある場面だけに置く。
- 画面下に次セクションが少し見える高さを維持する。

### セクション共通

- 大きな角丸カードを並べる構成にせず、罫線、番号、背景色の切り替え、余白で情報を整理する。
- 見出しの改行位置をPC・スマートフォンで固定し、一文字だけの行を作らない。
- 緑一色に寄せず、白、濃緑、赤、淡い青、生成りを役割ごとに使う。
- Tiki / Tetoは装飾ではなく、物語・聞く姿勢・社名の由来を伝える箇所に限定する。

## 新しい事業一覧

会社ホームの既存 `#services` に、現在と将来を同じ一覧で示す。既存リンクの互換性を守るため、アンカー名は変更しない。画面上の見出しは「事業一覧」とする。

1. AI導入・活用支援 / 提供中
   - AI担当者として業務整理から導入・定着まで伴走
   - `/ai/` へ遷移
2. コーチング・対話支援 / テスト提供中
   - 1on1、チーム対話、コミュニケーション研修
   - 問い合わせへ遷移
3. 外国人就労・定着支援 / 準備中
   - インドネシア人材を中心に、働く人と受け入れ企業の長期定着を支える構想
   - サービス提供中とは表現しない
4. ボードゲームカフェ・場づくり / 構想中
   - 子どもや若者、地域の人が同じテーブルを囲める場所
   - `/dream/boardgame-cafe/` へ遷移

## ヘッダー

デスクトップの「事業・サービス」をホバーまたはキーボードフォーカスで開くメニューにする。

- 事業一覧
- AI導入・活用支援
- コーチング・対話支援（テスト提供中）
- 外国人就労・定着支援（準備中）
- ボードゲームカフェ構想

「AI事業」は独立リンクとして残し、現在地を示す。スマートフォンではホバーを前提にせず、メニュー内に全項目を常時表示する。

ドロップダウンの操作仕様:

- 開閉トリガーは `button` とし、`aria-expanded` と `aria-controls` を同期する。
- マウスホバー、ボタンのEnter / Space、フォーカス流入で開く。
- Escape、外側クリック、フォーカスがメニュー外へ移動した時に閉じる。
- 上下矢印でメニュー項目を移動できるようにし、Escape後はトリガーへフォーカスを戻す。

## SEO実装ルール

- `/` と `/ai/` はそれぞれ自己参照canonicalを持つ。
- `/ai/` をサイトマップに含める。
- 既存記事のcanonicalは変更しない。
- AI記事には `/ai/` から内部リンクを張る。
- 会社ホームにはAI事業への説明付きリンクを置き、単なるメニューリンクだけにしない。
- ブログ一覧のtitleとdescriptionは「AI活用と会社の活動」の両方を説明する。
- `llms.txt` / `llms-full.txt` は会社ホームとAI事業ホームの二層構造に合わせる。
- 301は一段で正規URLへ到達させ、リダイレクトチェーンを作らない。
- ブログtitleは既存の `ブログ｜株式会社コールテン` を維持する。descriptionは「AI活用・導入事例と、コールテンの活動・考え方を発信しています。」へ拡張する。
- `/ai/` では、サービス詳細のURLを移動しないことが利用者にも分かるよう「AI事業のサービス」見出しの下から既存 `/services/` へ案内する。
